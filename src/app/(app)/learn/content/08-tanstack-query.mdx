TanStack Query (formerly React Query) is the library that manages **every piece of server data** in this app's client side. CLAUDE.md is dead serious about this: no `useEffect(() => { fetch... })`, no `useState` to hold loading/error flags. There's exactly one tool for fetching data, and this is it.

## What problem it solves

Before TanStack Query, you'd write something like this in every component:

## What TanStack Query gives you

A **cache** with a key, a **status** per key, and a **refresh** mechanism. You ask for `["rolls"]` and you get back the data, whether it's loading, when it last refetched, and what to do if it goes stale.

## The convention this app uses

Every query has its key and fetch function in a shared file under `src/lib/queries/`:

<AnnotatedCode
  filename="src/lib/queries/rolls.ts (essence)"
  language="ts"
  code={`import type { SupabaseClient } from "@supabase/supabase-js";
import type { Database } from "@/types/database";

export const rollsQueryKey = (userId?: string) =>
  userId ? (["rolls", userId] as const) : (["rolls"] as const);

export async function fetchRolls(
  supabase: SupabaseClient<Database>,
  userId?: string,
) {
  const q = supabase.from("rolls").select("*").order("created_at", { ascending: false });
  if (userId) q.eq("user_id", userId);
  const { data, error } = await q;
  if (error) throw error;
  return data;
}`}
  annotations={[
    {
      lines: [4, 5],
      title: "Key factory",
      body: "A function, not a constant. Because the key depends on params (which user are we querying?), the factory ensures the same params always produce the same key. 'as const' keeps the array's type narrow so TS knows exactly what shape it is.",
    },
    {
      lines: [7, 16],
      title: "Fetch function takes a SupabaseClient",
      body: "Crucially, fetchRolls doesn't import a Supabase client itself — it accepts one. That's how the same function works on the server (using the server client) AND on the client (using the browser client). One source of truth for how to fetch rolls.",
    },
  ]}
/>

This pattern shows up so often in CLAUDE.md it's worth memorizing: **query key factory + fetch function that takes a client**. That's the unit of the data layer here.

## What you can do with this knowledge

Whenever you need fresh data on the client side, the answer is `useQuery`. If you're tempted to grab data once with useEffect, stop — that's exactly the case the team has agreed not to allow, because it consistently produces bugs you only catch in production. The query keys file in `src/lib/queries/` is the place to look first; the function you need may already exist.
